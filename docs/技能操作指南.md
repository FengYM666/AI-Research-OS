## ✨ 提示词优化器（prompt-optimizer MCP，9-07 新装）

**你说糙话 → 我先转成专业提示词给你过目 → 你确认后我才动手**。本地服务，智谱 glm-4.5-flash 免费模型，不花钱。

| 场景 | 你就这么做 | 会发生什么 |
|------|-----------|-----------|
| 日常提需求 | 直接说，比如 `帮我想个 3DGS 方向的实验方案` | 我先调优化器把需求转成结构化专业提示词，**给你看，你点头我才干** |
| 结果不满意 | 说 `第3点不对，我用的是手机拍照不是单反` | 我用 iterate-prompt 迭代修改，改到你满意 |
| 优化系统提示词 | `帮我把这段角色设定优化一下` | 走 optimize-system-prompt |

> ⚠️ 优化器会自己脑补细节（场景、数量、工具型号），**结果一定要扫一眼再放行**。细节不对直接指出来，别客气。
> 🔧 服务随开机自启，不用你管。如果我说"连不上优化器"，告诉我一声即可（一条命令拉起）。

## 🎓 学术研究全流程（主力工作流）

按科研顺序排的，每个环节直接照抄"你就这么说"即可（以你的 3D 生成/重建方向为例）。

### ① 定方向、找研究空白、评估想法

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `/phd-skills:gaps 3D 高斯泼溅的实时渲染` | 扫文献找还没人做的空白点，给出候选研究切入点 |
| `帮我调研一下 NeRF 方向还有什么开放问题` | 文献调研 + 开放问题清单 |
| `评估一下我这个 idea 值不值得做` | idea-evaluator：博导五维打分（更高/更快/更强/更省/更广）+ 致命伤审计，弱 idea 趁早枪毙 |

### ② 查文献（paper-search MCP + paper-search 技能）

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `帮我找近三年 3DGS 压缩方向的顶会论文，要有代码的` | 走 20 个学术源检索（arXiv/OpenAlex/dblp/谷歌学术…），五要素核实后才列出来，绝不编造 |
| `把这三篇的 PDF 下载下来` | 直接下载到本地 |
| `验证一下这个参考文献是不是真的` | dblp/官网逐条核对标题、作者、年份、会议 |
| `把这篇论文存进我的文献库` / `我库里那篇 3DGS 的引用给我` | 走 zotero MCP 管你的文献库（⚠️ Zotero 要开着） |
| `把这篇英文论文翻译成中文` | 用 pdf2zh_next 翻译 PDF，公式排版原样保留 |

> 🔒 铁律：每篇论文必须真实可查证，查不到会明说"没查到"，不会瞎编。

### ③ 精读论文

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `精读这篇论文` + PDF 路径 | paper-study：出深度学习材料、抽图 |
| `总结这篇论文` / 丢 arXiv 链接 | paper-summary：快速看核心观点 |

### ④ 复现 & 跑实验（phd-skills）

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `帮我复现这篇论文` + arXiv 链接 | reproduce：读论文→找代码→补缺失超参→跑 smoke test→复现实验 |
| `我要启动一个训练任务` | launch：起飞前检查单——配置 diff、路径验证、监控设置，防"跑 50 小时发现错了" |
| `对比一下 run A 和 baseline` | compare：同 epoch 对齐比 wandb 曲线，不拿"别人的最终成绩 vs 你的中途成绩" |
| `loss 发散了 / OOM 了 / 训练卡住了` | debug：先看 GPU/日志/检查点取证，再下结论，不瞎猜 |
| `帮我设计一组消融实验` | experiment-design：消融怎么排、baseline 怎么选、成本预估 |
| `/phd-skills:xray` | 论文对着代码五维审计：论文里说的和代码做的是否一致 |
| `分析这个数据集的偏差` | dataset-curation：数据集偏差/分层抽样/公平性 |

### ⑤ 画图（scientific-visualization + figure-designer）

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `把这个实验结果画成论文图` | 出版级 matplotlib 图：多面板、不确定性表达、配色过可访问性审计 |
| `帮我设计 Figure 1 动机图 / 方法总览图` | figure-designer：按顶会审美设计三核心图的范式、布局、标注 |
| `检查这张图能不能投 CVPR` | 对照目标期刊/会议的最新图表要求核查 |

> 🔒 它有"数据诚信护栏"：不许美化数据、不许藏不利数据点——你的图永远经得起审稿人推敲。

### ⑥ 写论文 & 投稿防守

| 你就这么说 | 会发生什么 |
|-----------|-----------|
| `帮我搭一下论文的逻辑骨架` | tech-paper-template：背景→挑战→贡献对齐的思考模板 + 四点自查 |
| `帮我写/改 Introduction`（或任何章节） | research-paper-writing：彭思达（浙大 CV）方法论，顶会各章节写法 |
| `帮我把这段中文改成投稿级英文` / `润色这段话` | paper-polish：忠于原意润色 + 中译英改写，绝不动科学含义 |
| `检查这一章的记号一致性和图文对应` | paper-writing：符号、图表、claim-evidence 对齐 |
| `投稿前给我做个体检查` | pre-submission-reviewer：五维审查（逻辑/语法/LaTeX/图表/AI 腔词汇黑名单），按严重级别输出 |
| `审稿人会挑我什么毛病？` | reviewer-defense：预判审稿问题 + rebuttal 准备 |
| `/phd-skills:fortify CVPR` | 选最强消融组合 + 按目标会议预判审稿人 |
| `/phd-skills:factcheck` | BibTeX 逐条对 dblp，专抓假引用（投稿前必跑） |
| `帮我配 LaTeX 环境 / 编译报错` | latex-setup |

> 🧭 总规矩（vibe-research-workflow）：机械活（写代码、画图、润色）外包给 AI，学术判断（方向、实验设计、事实准确性）必须你自己把关——这是港科大博导定的协作纪律。

## 📊 快速参考：最常用的一屏

```
── 科研 ──
"帮我找近三年 XX 方向的顶会论文，要有代码"  → 查文献
/phd-skills:gaps XX                        → 找研究空白定方向
"精读这篇论文" + PDF                        → 深度学习材料
"帮我复现这篇论文" + arXiv 链接             → 复现全流程
"loss 发散了"                              → 实验诊断
"把这个结果画成论文图"                      → 出版级图表
"帮我写 Introduction"                     → 顶会写作
/phd-skills:factcheck                      → 投稿前查假引用

── 日常 ──
"用 caveman"        → 开精简模式（省 token）
"最简方案"          → ponytail 懒人模式
"帮我规划这个任务"   → 文件规划三件套
"做个 PPT"          → 内置 pptx 技能
```

### 三技能协同（你自己的工作流）

```
复杂任务？  → 文件规划先写计划
要写代码？  → ponytail 先过最简阶梯
写完了？    → 质量门（security-review → code-review → 测试）
冲突时听谁的：ponytail > ECC > 文件规划（省 token 优先）
```
